Archive Function

Records marked Inactive, Deceased, or Transferred are moved to this archive so that only ACTIVE senior citizens appear in the main dashboard and processing lists. Archived records remain fully recoverable, duplicate and fragmented records are eliminated through the integrity scan, and an automatic daily backup with a data recovery plan protects all records.

Manage Seniors

Review every senior account in one place. Use Edit to correct the senior's account information (name, Senior ID, contact, address, birth date, sex, civil status, barangay/city/province). Use Deceased when a senior citizen has passed away — the account is moved to the Archive (recoverable by OSCA staff), stops receiving any pension or benefit, and is blocked from logging in. All changes are saved to the account and recorded in the system audit trail.
